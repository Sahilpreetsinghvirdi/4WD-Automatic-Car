# 4WD-Automatic-Car
A 4WD autonomous robot car powered by Arduino Mega, featuring multi-directional obstacle detection, intelligent path selection, automatic reversing, LCD feedback, buzzer alerts, and dual navigation modes for fully autonomous movement.
